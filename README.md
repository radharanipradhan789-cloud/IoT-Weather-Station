# 🌦️ IoT Weather Station Using ESP32 and DHT22

## 📌 Project Overview

The IoT Weather Station is an environmental monitoring project that uses an ESP32 microcontroller and a DHT22 temperature and humidity sensor. It is designed to collect environmental readings and support online monitoring through ThingSpeak.

## 🎯 Objectives

* Measure temperature and humidity.
* Read sensor data using an ESP32.
* Display sensor readings in the Serial Monitor.
* Send readings to ThingSpeak for online visualization.
* Explore IoT-based environmental monitoring.

## Technologies and Tools

* ESP32
* DHT22 Temperature and Humidity Sensor
* Arduino IDE
* ThingSpeak IoT Platform
* Wokwi Simulator (if used for simulation)

## Working Principle

1. The DHT22 sensor measures temperature and relative humidity.
2. The ESP32 reads the sensor values.
3. The readings are displayed in the Serial Monitor.
4. The ESP32 can send the readings to ThingSpeak through a Wi-Fi connection.
5. ThingSpeak displays the collected data in charts for monitoring.
